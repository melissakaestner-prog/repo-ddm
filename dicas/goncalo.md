# Dica Git: git remote add upstream

### O que faz

Liga ao repositório original (o da professora). Útil porque permite trabalhar na versão do projeto, sem afetar a original. Depois, podemos enviar as mudanças para o repo original.

### Exemplo

Ligar ao repositório fixe da prof e depois verificar a ligação:

```bash
git remote add upstream https://github.com/melissakaestner-prog/repo-ddm

git remote -v
